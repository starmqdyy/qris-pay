# QRIS Payment Page

Repository ini berisi halaman statis pribadi untuk menampilkan QRIS pembayaran milik **starmqdyy**.

## Tujuan

Project ini dibuat sebagai halaman sederhana agar QRIS dapat dibuka melalui sebuah tautan dan dipindai oleh pengguna yang ingin melakukan pembayaran.

## Batasan

Repository ini:

- bukan payment gateway;
- bukan aplikasi perbankan;
- tidak memproses transaksi;
- tidak menyimpan data pembayaran;
- tidak meminta PIN, OTP, password, atau informasi kartu;
- tidak menjamin status pembayaran secara otomatis.

Seluruh proses pembayaran dilakukan langsung melalui aplikasi pembayaran atau perbankan milik pengguna.

## Cara Menggunakan

1. Buka halaman QRIS.
2. Pindai kode menggunakan aplikasi pembayaran yang mendukung QRIS.
3. Periksa nama penerima dan nominal sebelum mengonfirmasi pembayaran.
4. Simpan bukti pembayaran bila diperlukan.

## Keamanan

Pastikan URL yang dibuka berasal dari repository atau halaman resmi milik:

```text
github.com/starmqdyy
```

Jangan melakukan pembayaran apabila nama penerima atau informasi transaksi tidak sesuai.
