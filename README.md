# QRIS Payment Page

Proyek sederhana untuk integrasi QRIS payment gateway menggunakan HTML + CSS + JavaScript.

### Tech Stack
- HTML5
- CSS3
- JavaScript

### Rencana Pengembangan Selanjutnya
- Integrasi AI untuk deteksi QR code otomatis (menggunakan PyTorch + AMD ROCm)
- Deployment ke cloud (AMD Developer Cloud)

✨ Sedang belajar ROCm & AMD GPUs untuk mempercepat model AI di proyek-proyek mendatang.
